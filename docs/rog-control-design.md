drawing rules, verification) are kept there, in
[rog-control-macos/docs/rog-control-design.md](https://github.com/thanhnndev/rog-control-macos/blob/main/docs/rog-control-design.md).

The copy that used to be here described an older window layout (tabs, no visual language section) and is no longer
maintained. A UI/UX review of the current app (0.3.3) and the Setup app design built on it are in
[FRESH-INSTALL.md section 6](FRESH-INSTALL.md#6-setup-app-uiux-based-on-rog-control).
