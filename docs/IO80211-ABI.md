# `IO80211Controller` ABI on macOS 15 (Darwin 24.6.0)

Step 1 of option C in `WIFI-AS-WIFI.md`: what a subclass of `IO80211Controller` has to provide. Everything here is read
from symbol names and vtable data in Apple's `BootKernelExtensions.kc`; no function body was disassembled and no Apple
or `itlwm` source was used. Semantics of each method are **not** established by this page.

* Input: `BootKernelExtensions.kc` of Darwin 24.6.0 (`xnu-11417.140.69.712.69`), taken from the installer copy on the
  macOS Data volume (`Previous Content/com.apple.installer/`). Same Darwin version as the installed 15.8.1.
* Tool: `tools/kc.py` (Capstone is only needed for `disasm`; symbols and vtables work without it).
* Layout is per macOS build. Re-run the snippet below on any other version before trusting the offsets.

## Vtable

`__ZTV17IO80211Controller` has **466 slots** (0xE90 bytes, 2 header slots + 464 functions). The fileset entry pointers
are kernel-cache chained fixups (low 30 bits = offset from the KC base `0xffffff8000100000`).

| Slots | Offsets | Owner |
|---|---|---|
| 2-132 | 0x10-0x420 | `OSObject`, `IORegistryEntry`, `IOService` (as in MacKernelSDK) |
| 133-395 | 0x428-0xC58 | `IOService` tail, `IONetworkController`, `IOEthernetController` (as in MacKernelSDK) |
| **396-465** | **0xC60-0xE88** | **new virtuals of `IO80211Controller`** |

Overrides `IO80211Controller` makes in the inherited range: `init(OSDictionary*)` (slot 75), `free` (20), `start` (186),
`stop` (187), `configureReport` (135), `updateReport` (136), `getWorkLoop` (211), `stringFromReturn` (242),
`errnoFromReturn` (243), `getFeatures` (270), `newVendorString` (271), `newModelString` (272), `createWorkLoop` (308),
`getHardwareAddress` (358), `setMulticastMode` (360), `setPromiscuousMode` (362), `setMulticastList` (464).

## Consequences for the plan

* The class is Skywalk-only on Sequoia: every pure virtual takes an `IO80211SkywalkInterface*`, and `start` expects the
  work queue and command gate. A subclass that skips them is not safe; this matches the warning in
  `WIFI-AS-WIFI.md`.
* `IO80211SkywalkInterface`, `IO80211InfraInterface`, `IO80211Family`'s `IO80211WorkQueue`/`IO80211CommandGate` and
  `apple80211_*_data` structs are separate ABI surfaces and are **not** mapped yet. That is the next step (same method:
  vtable + `kc.symname`, then struct layouts from how `AppleBCMWLANCore` uses them).
* Building a `.kext` that links against these private symbols needs a stub `IO80211Family` dependency
  (`com.apple.iokit.IO80211Family`) and a header written from this table, not from `itlwm`.

## Reproduce

```python
import os, struct, sys
os.environ["KC"] = "/mnt/macos-vol0/Previous Content/com.apple.installer/BootKernelExtensions.kc"
sys.path.insert(0, "tools"); import kc
BASE = 0xffffff8000100000
vt = next(a for a, n in kc.syms.items() if n == "__ZTV17IO80211Controller")
nxt = next(a for a in kc.sorted_addrs if a > vt)
for i in range((nxt - vt) // 8):
    v = struct.unpack_from("<Q", kc.d, kc.va2off(vt) + i * 8)[0]
    t = BASE + (v & 0x3fffffff) if v else 0
    print(i, hex(i * 8), kc.syms.get(t) or "-")
```

## Tahoe (macOS 26.7.1, 25G241, Darwin 25.6.0) vs Sequoia 24H32

Collected on Linux from the mounted System volume (`abi/native-wifi/25G241/`, same tool set, `tools/collect_native_wifi_abi.py`).

| Class | Slots 24H32 -> 25G241 | Result |
|---|---|---|
| `IO80211Controller` | 466 -> 466 | **identical vtable** |
| `IO80211CommandGate`, `IO80211WorkQueue`, `IO80211ControllerMonitor` | unchanged | identical |
| `IO80211SkywalkInterface` | 463 -> 464 | changed: `IOSkywalkNetworkInterface::setRxFlowSteering` inserted (slot ~296), `setLinkState(IO80211LinkState,bool,uint)` removed, `setRxDataStallStats` added, `createLinkQualityMonitor(IO80211Peer*,IOService*)` -> `(IO80211Peer*,bool)`, `willTerminate` now resolves to `IOSkywalkNetworkInterface` |
| `IO80211InfraInterface`, `IO80211VirtualInterface`, `IO80211Peer`, `AppleBCMWLAN*` | +2 to +13 slots | changed |

So the controller half (what `itlmt7925Native` subclasses) keeps its ABI; the interface half that the native driver publishes through (`IO80211SkywalkInterface`, Skywalk queues) moved. `kexts/itlmt7925Native` must regenerate its header (`tools/gen_io80211_header.py`) from `25G241` and re-verify every use of the interface vtable (setLinkState is gone, `createLinkQualityMonitor` changed) before MaxKernel is lifted. Until then `itlmt7925Native` stays capped at 24.99.99; the Ethernet-style `itlmt7925` (no IO80211) is what loads on Tahoe.
