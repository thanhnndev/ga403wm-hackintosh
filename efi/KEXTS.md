# Kexts of the reference EFI

Third-party kexts are **not** redistributed here. Get each from its upstream project and check the executable against
[`kexts.json`](kexts.json) (SHA-256 of the binary used on the reference machine; a newer release is fine, the hash is only
there so you can reproduce the exact setup).

`Kernel > Add` order matters: Lilu first, then VirtualSMC, then everything that depends on them; VoodooInput/VoodooGPIO/
VoodooI2CServices before VoodooI2C, VoodooI2CHID last.

## From this repository

| Kext | Bundle id | Role | Needed |
|---|---|---|---|
| `itlmt7925.kext` | `com.itlmt7925.kext` | MT7925 Wi-Fi: firmware, scan, WPA2-PSK, Ethernet interface (`docs/WIFI.md`) | for Wi-Fi |
| `ItlXhciKick.kext` | `com.itlmt7925.xhcikick` | services the second xHCI event ring of single-vector AMD controllers (`docs/USB-XHCI-LAG.md`) | **yes**, without it USB keyboards/mice lag ~2 s |
| `ItlDiag.kext` | `com.itlmt7925.diag` | boot diagnostics, NVRAM digest, optional USB-stick log (`docs/DEBUGGING.md`); **disabled** in the reference config | no |
| `AsusWmi.kext` | `com.itlmt7925.asuswmi` | ASUS WMI/EC/HID: profiles, fan curves, charge limit, keyboard light, Slash (`docs/ASUSCTL-MACOS.md`) | for RogControl |
| `AmdCppc.kext` | `com.itlmt7925.amdcppc` | Zen 5 CPPC/boost/EPP control, clocks, Tctl, RAPL (`docs/CPU-POWER.md`) | for full CPU speed |
| `MtkBtFw.kext` | `com.itlmt7925.mtkbtfw` | loads the MT7925 Bluetooth firmware over USB (`docs/BLUETOOTH.md`) | for Bluetooth |
| `BtLeDlFix.kext` | `com.itlmt7925.btledlfix` | Lilu plugin: BLE mice with `bluetoothd` (`docs/BLUETOOTH.md`) | experimental |

## Third-party

|---|---|---|

| AMFIPass 1.4.1 | <https://github.com/dortania/OpenCore-Legacy-Patcher> (payload, SHA-256 of the zip `07b26614…`) | Lilu plug-in that lets WindowServer (a platform binary) load the ad hoc signed NullMoth driver; required since NullMoth 1.10 |
| VirtualSMC 1.3.9 | <https://github.com/acidanthera/VirtualSMC> | SMC emulation |
| SMCBatteryManager 1.3.9 | VirtualSMC release | battery status |
| SMCLightSensor 1.3.9 | VirtualSMC release | ambient light; **disabled** in `config.plist` |
| AppleALC 1.9.9 | <https://github.com/acidanthera/AppleALC> | audio, `layout-id` 33 on the HD-audio controller |
| AppleMCEReporterDisabler 1.2 | Dortania AMD guide | stops the AppleIntelMCEReporter panic on AMD |
| BlueToolFixup 2.7.2 | <https://github.com/acidanthera/BrcmPatchRAM> (release zip) | lets `bluetoothd` accept a non-Apple controller (needed by `MtkBtFw`); also needs its NVRAM variables |
| BrightnessKeys 1.0.4 | <https://github.com/acidanthera/BrightnessKeys> | brightness hot keys |
| ForgedInvariant 1.5.0 | <https://github.com/ChefKissInc/ForgedInvariant> | TSC synchronisation on AMD |

| RestrictEvents 1.1.7 | <https://github.com/acidanthera/RestrictEvents> | CPU name (`revcpu`), `sbvmm` patch via NVRAM variables |
| WhateverGreen 1.7.2 | <https://github.com/acidanthera/WhateverGreen> | **disabled** in `config.plist`, not used by this configuration |
| NullEthernet 1.0.6 | RehabMan's OS-X-Null-Ethernet | the fake `en0` that `SSDT-RMNE` describes |
| HoRNDIS 9.3 | <https://github.com/jwise/HoRNDIS> | USB tethering from an Android phone (network while installing) |

| USBToolBox 1.2.0 | <https://github.com/USBToolBox/kext> | USB port map consumer |
| UTBMap 1.0 | the author's USB map for the GA403WM (in the release `EFI-reference.zip`, `OC/Kexts/UTBMap.kext`) | enabled; fits this model only, map your own ports elsewhere |
| UTBDefault 1.0 | generated by the USBToolBox tool | **placeholder** map, no ports defined; **disabled** |

| VoodooI2CHID 1.0 | <https://github.com/VoodooI2C/VoodooI2CHID> | I2C-HID satellite: the `093a:3011` touchpad |

All Acidanthera kexts use the Lilu/VirtualSMC release zips; the Voodoo plug-ins ship inside the VoodooI2C release.
